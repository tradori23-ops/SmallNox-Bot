# SmallNox Bot Starter

## Install
Open Terminal in this folder and run:

```bash
python3 -m pip install -r requirements.txt
```

## Add your token
Duplicate `.env.example`, rename the copy to `.env`, and replace the placeholder with your real Discord bot token.

Never share your bot token.

## Start SmallNox
```bash
python3 bot.py
```

Included slash commands:
- /help
- /site
- /comics
- /roleplay
- /music
